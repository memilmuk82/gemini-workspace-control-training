# 연수용 교과 평가 맥락

이 문서는 실제 특성화고 평가계획의 성취기준과 평가요소를 연수 실습용으로 비식별·재구성한 자료다.

- 교사명·학교명·학생명·학번·성적·제출물은 포함하지 않는다.
- 실제 평가 결과가 아니라 AI 출력의 정합성을 검증하기 위한 기준 자료다.
- 아래 평가항목의 의미와 배점 체계를 임의로 바꾸거나 새 항목을 추가하지 않는다.

## 기준 사례 A — 파이썬프로그래밍

### 수행평가 과제

Flask 데이터 바인딩 및 1:1 코드 디펜스

### 관련 성취기준

- 변수의 개념을 이해하고 자료형의 특징에 따라 적절한 변수를 선언하여 사용할 수 있다.
- 순차·선택·반복 제어 구조를 이해하고 활용하여 프로그램을 작성할 수 있다.

### 평가항목

1. 환경 설정: Flask 기본 구동과 라우팅 환경을 설정하고 브라우저 연결 오류가 없는가?
2. 변수 선언: 웹 화면에 출력할 복합 데이터(List, Dictionary 등)를 알맞은 파이썬 변수로 선언했는가?
3. 제어문 적용: Jinja2 템플릿과 파이썬 제어문(for, if)을 연동하여 웹 화면에 데이터를 동적으로 출력했는가?
4. 일지 기록: 오류 발생 현상, AI(Gemini)에 입력한 프롬프트, 해결 과정을 Google Sites 작업 일지에 빠짐없이 기록했는가?
5. 코드 디펜스: 작성한 변수와 제어문의 논리적 흐름, 웹 화면 출력 원리를 교사에게 구체적으로 설명할 수 있는가?

### 성취수준 요약

- 상: Flask 환경에서 변수와 제어문을 반복적으로 적용하고 코드의 작동 원리를 1:1로 구체적으로 설명할 수 있다.
- 중: 변수와 제어문을 부분적으로 활용해 데이터를 바인딩할 수 있고 전체 코드의 기초 흐름을 설명할 수 있다.
- 하: 도움을 받아 변수와 제어문을 적용할 수 있으나 작동 원리의 구두 설명에 어려움이 있다.

## 기준 사례 B — 응용 프로그래밍 개발

### 실습 맥락 1: 기본 개발 환경과 형상관리

- 클라우드 IDE에서 프로젝트 워크스페이스를 생성한다.
- 가상환경을 만들고 Flask를 설치하며 설치 오류가 없는지 확인한다.
- MVC/MVT 구조에 맞춰 app.py, static/, templates/를 구성한다.
- requirements.txt로 의존성을 기록한다.
- git init, .gitignore, 최초 커밋, 원격 저장소 연결, git push를 수행한다.
- Flask 라우팅, 서버 구동, HTML 템플릿, CSS 연결, 브라우저 최종 렌더링을 확인한다.

### 실습 맥락 2: 인터랙티브 데이터 핸들러

- GET/POST 메서드를 구분하고 request.form 또는 request.args로 데이터를 수신한다.
- 수신 데이터를 용도에 맞는 자료형으로 변환하고 백엔드 변수에 할당한다.
- 기능별 라우팅과 처리 후 페이지 이동을 구현한다.
- Create, Read, Update, Delete 동작과 화면 반영을 확인한다.
- 잘못된 입력에 대한 예외 처리, 명명 규칙, 주석, 모듈화, 사용자 피드백을 점검한다.

### 실습 맥락 3: 외부 API 연동 및 확장

- API 키를 코드에 직접 넣지 않고 환경변수나 별도 파일로 관리한다.
- requests 등을 사용해 요청 코드를 작성하고 필수 파라미터와 인증 헤더를 구성한다.
- HTTP 상태 코드로 통신 성공 여부를 확인한다.
- JSON 응답에서 필요한 값을 추출하고 템플릿에 바인딩한다.
- 예외 처리, 사용자 안내 메시지, 기본값, Timeout, 안전한 오류 로그를 적용한다.

### 실습 맥락 4: 데이터베이스와 클라우드 배포

- 테이블과 컬럼을 ERD 또는 스키마로 설계하고 자료형과 기본키를 지정한다.
- DB 연결 문자열을 설정하고 테이블 생성 또는 연결을 확인한다.
- CRUD 동작과 상태 갱신을 확인한다.
- 클라우드 배포 프로젝트, 소스 배포, 필수 환경변수, 외부 URL 접속을 확인한다.
- 로컬과 클라우드 환경의 차이와 주요 오류 해결 과정을 설명한다.

### 실습 맥락 5: 검색과 정렬

- 외부 API 또는 DB의 원시 데이터를 List·Dictionary·JSON으로 변환한다.
- 검색 키워드와 일치하는 항목을 찾고 결과가 없을 때 안내 메시지를 표시한다.
- 사용자가 정렬 기준과 오름차순·내림차순을 선택할 수 있게 한다.
- 자료형 오류, KeyError, 빈 결과 같은 예외 상황을 처리한다.

## 연수에서 사용할 공통 판정 질문

1. AI가 평가계획에 없는 평가항목을 새로 만들었는가?
2. 평가항목의 의미를 다른 개념으로 바꾸었는가?
3. 충족 개수와 점수의 대응을 정확히 유지했는가?
4. 실제 학생의 성향·수준·점수·학교 정책을 추정했는가?
5. 코드와 작업 일지에서 직접 확인할 수 있는 증거로 표현했는가?
6. 게시·평가·자동 실행 전에 교사가 확인할 지점이 남아 있는가?
