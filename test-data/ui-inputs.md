# Evidence Capture용 입력 문구

이 파일의 문구는 실제 UI에 복사해 쓰기 위한 가상 데이터다. 실제 학생·학교·평가 데이터가 아니다.

## 01. Gemini in Classroom

### 가상 과제

```text
[연수용 가상 과제] 지역 축제 홍보 포스터 기획안

특성화고 디자인과 2학년 학생이 지역 축제의 목표 독자를 정하고 A3 홍보 포스터 시안을 기획합니다. 콘셉트 보드 1장, 200자 이내 기획 의도, 사용 서체·색상 근거를 제출합니다. 타깃 적합성, 시각적 위계, 선택 근거, 완성도를 평가합니다. 실제 학생에게 게시하지 않고 연수용 초안으로만 만듭니다.
```

### 루브릭 생성 요청

```text
이 과제의 분석적 루브릭을 작성해 줘. 평가 기준은 타깃 적합성, 시각적 위계, 선택 근거, 완성도 네 가지이고, 각 기준을 4·3·2·1점의 관찰 가능한 문장으로 작성해. 총점은 16점이야. 실제 학생 특성이나 학교 정책은 추정하지 마.
```

## 02. 좋은 Prompt

### Before

```text
포스터 과제 루브릭 만들어줘.
```

### After

```text
당신은 특성화고 디자인과 수행평가를 설계하는 교사다. 2학년 학생이 지역 축제 홍보 포스터 기획안을 제출하는 과제의 분석적 루브릭을 작성하라. 평가 기준은 타깃 적합성, 시각적 위계, 선택 근거, 완성도 4개이며 각 기준을 4·3·2·1점의 관찰 가능한 문장으로 기술하라. 총점은 16점이다. 결과는 마크다운 표로 제시하고, 추정한 내용은 표 아래에 별도로 표시하라.
```

## 03. Harness — 연수 통제 프레임

```text
역할: 특성화고 디자인과 평가설계 조교.
작업: 아래 과제 설명만 근거로 16점 분석적 루브릭을 작성한다.
입력 범위: 제공된 과제 설명과 네 가지 평가 기준만 사용한다.
제약: 학생 특성이나 학교 정책을 추정하지 않는다. 관찰 불가능한 태도 표현을 쓰지 않는다.
출력 계약: 기준×4수준 표, 각 셀 35자 이내, 마지막에 확인 필요 항목 목록.
검증: 총점이 16점인지, 네 기준이 모두 있는지, 근거 없는 가정이 없는지 자체 점검표를 붙인다.
근거가 부족하면 임의로 채우지 말고 '확인 필요'라고 표시한다.

과제 설명:
특성화고 디자인과 2학년 학생이 지역 축제 홍보 포스터 기획안을 제출한다. 제출물은 콘셉트 보드 1장, 200자 이내 기획 의도, 사용 서체·색상 근거다. 평가 기준은 타깃 적합성, 시각적 위계, 선택 근거, 완성도다.
```

## 04. Verification Loop — 연수 통제 프레임

```text
방금 만든 결과를 바로 수정하지 말고 먼저 감사하라. 각 주장 또는 평가 기준을 `검증 가능 / 모호함 / 근거 부족`으로 분류하고 이유를 표로 제시하라. 그다음 입력 자료에서 직접 확인되는 내용만 남겨 수정본을 작성하라. 마지막에 사람이 원문과 대조해야 할 항목을 나열하라.
```

## 05. Classic Gem

이름:

```text
수행평가 루브릭 점검관 (연수용)
```

지침:

```text
당신은 특성화고 수행평가 루브릭의 정합성을 점검하는 검토자다. 사용자가 제공한 과제 설명과 루브릭만 비교한다. 결과는 1) 누락 조건 2) 관찰 불가능한 표현 3) 배점 오류 4) 교사 확인 필요 항목 순서로 작성한다. 학생의 성향, 학교 정책, 교육과정 내용을 추정하지 않는다. 근거가 없으면 '확인 필요'라고 표시한다.
```

Preview 입력:

```text
과제는 콘셉트 보드와 기획 의도, 서체·색상 근거를 제출하게 되어 있어. 그런데 루브릭은 창의성 10점, 성실성 10점으로만 구성되어 있어. 문제를 점검해 줘.
```

## 07. Workspace Studio

```text
내가 연수용 설문 응답을 받으면 응답 내용을 Gemini로 세 문장 요약하고, 후속 확인이 필요한 항목을 별도 목록으로 만드는 흐름을 생성해 줘. 외부 사람에게 이메일이나 채팅을 보내지 마.
```

Test run용 가상 응답:

```text

```

## 08. Gems from Google Labs

```text
교사가 과제 설명을 붙여 넣으면 목표, 제출물, 평가 기준, 확인 필요 항목의 네 영역으로 정리하는 한국어 점검 앱을 만들어 줘. 입력에 없는 내용은 추정하지 말고 '확인 필요'라고 표시해. 결과를 복사하기 쉬운 표로 보여 줘.
```

앱 검증 입력:

```text
2학년 디자인과 학생이 지역 축제 포스터를 기획한다. 콘셉트 보드와 200자 기획 의도를 제출한다. 평가 기준은 타깃 적합성과 정보 위계다.
```

## 09. Spark / Skills

Skill 이름:

```text
교육 자료 근거 점검 (연수용)
```

Skill 지침:

```text
사용자가 준 텍스트에서 사실 주장만 추출하고, 각 주장에 대해 원문 근거 문장을 연결한다. 근거가 없으면 '확인 필요'로 표시한다. 결과는 주장/근거/상태의 표로 만든다. 이메일 발송, 일정 생성, 파일 수정, 외부 게시를 하지 않는다.
```

Task:

```text
Google 공식 도움말 한 페이지만 근거로 해당 기능의 사용 조건과 제한을 정리해 줘. 내가 지정한 '교육 자료 근거 점검 (연수용)' Skill을 사용하고, 출처 링크를 포함해. 외부 서비스에 쓰기 작업은 하지 마.
```
