# 100분 실습형 강의 구조 — 통합 표시 153장

## 설계 원칙

- 한 화면에 여러 단계가 함께 있어야 맥락이 보이는 경우에는 입력과 결과를 함께 제시한다.
- 각 기능은 `준비 → 진입 → 입력 → 설정 → 생성 → 검증 → 수정 → 결과`를 빠짐없이 보여준다.
- 화면 전체 맥락이 필요한 장면은 전체 화면으로, 실제 글을 읽어야 하는 입력·결과만 제한적으로 확대한다.
- 모든 실습은 가상 과제와 합성 데이터로 진행하며 실제 학생 개인정보·성적·제출물은 사용하지 않는다.
- `Harness`는 작업 조건을 설계하는 방법, `Verification Loop`는 초안을 반복 검증하는 방법으로 설명한다.
- 계정이나 기능이 없는 참가자를 위해 `직접 실행`과 `화면 관찰·판정`의 대체 실습을 함께 둔다.
