# 웹 슬라이드 디자인 시스템

## 시각 방향

교사의 통제권을 강조하는 `Control Console × Annotated Field Manual`이다. 표지는 짙은 잉크 네이비의 단일 무대, 본문은 실제 UI를 검토하는 흰색 편집 지면으로 전환한다.

## 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | `#061831` | 표지 배경, 레일, 주요 텍스트 |
| `--ink-soft` | `#12345f` | 보조 네이비 |
| `--blue` | `#1d5cff` | 현재 단계, 링크, 핵심 구조 |
| `--lime` | `#b7e400` | 검증 완료, 근거 확인 |
| `--coral` | `#ff675d` | 위험·추정·주의 |
| `--paper` | `#ffffff` | 본문 슬라이드 배경 |
| `--surface` | `#f4f7fb` | 캡처·표·예시의 옅은 바탕 |
| `--line` | `#d8dee8` | 구분선과 프레임 |
| `--muted` | `#5d6b7e` | 설명·출처·보조 문구 |

그라디언트·글래스모피즘·과도한 그림자는 사용하지 않는다.

## 타이포그래피

- 기본: `Pretendard Variable`, `Pretendard`, `SUIT`, `Noto Sans KR`, 시스템 산세리프
- 표지 제목: 92–124px, 800–900
- 본문 제목: 54–68px, 780–850
- 섹션 제목: 86–104px, 820–900
- 본문: 25–32px, 500–650, 줄간격 1.45–1.6
- 주석·출처: 16–20px, 500–650
- UI 컨트롤: 15–17px, 650–750

## 16:9 그리드

- 기준 크기: `1600 × 900` CSS px
- 안전 여백: 좌우 80px, 상하 58px
- 본문 슬라이드 왼쪽 레일: 78px
- 본문 콘텐츠: 12열, 열 간격 24px
- 캡처 프레임: 16:9 또는 실제 화면 비율, 1px 네이비 테두리, 10px 이하 반경

## 컴포넌트

- `cover-route`: 9개 교육 흐름을 하나의 선으로 연결
- `section-rail`: 슬라이드 번호·기능명·진행 위치
- `evidence-frame`: 실제 UI 캡처 전용 프레임
- `privacy-mask`: 표시명·프로필 배지·개인화 목록을 가리는 흰색/표면색 HTML 요소
- `callout`: 번호 원, 선, 짧은 판정 문장
- `control-loop`: 입력 → 생성 → 근거 대조 → 교사 결정
- `status-note`: `확인`, `확인 필요`, `실제 UI 차이` 세 종류
- `timing-bar`: 1부 50분 / 휴식 10분 / 2부 50분

## 아이콘

선형 SVG를 사용한다. 획은 `2px`, 둥근 캡·조인을 기본으로 하고, 검증은 원 안의 체크, 주의는 삼각형, 단계 이동은 단순 화살표로 통일한다.

## 개인정보 처리

원본 PNG는 변경하지 않는다. 공개 슬라이드에서는 프레임의 `overflow: hidden`, 확대·위치 조정, `privacy-mask`로 표시명·프로필 사진·개인화 목록을 제외한다. 인쇄 모드에서도 마스크가 유지되어야 한다.

## 모션

- 슬라이드 전환: 160ms opacity + 12px translate
- 콜아웃 등장: 180ms stagger
- `prefers-reduced-motion: reduce`에서는 즉시 전환
