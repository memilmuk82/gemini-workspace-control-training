# 콘셉트-구현 일치 기록

## 유지한 요소

1. 짙은 잉크 네이비 표지와 흰색 본문 지면의 대비를 유지했다.
2. 본문 왼쪽에 슬라이드 번호와 섹션명을 담는 고정 레일을 유지했다.
3. 코발트 블루를 진행·근거 색으로, 라임을 검증 단계 색으로 사용했다.
4. 실제 Google UI만 이미지로 사용하고 설명·표·번호는 HTML/CSS로 구성했다.
5. 캡처 프레임을 네이비 1px 선으로 고정해 증거 화면의 경계를 명확히 했다.

## 사용자 검토 뒤 변경한 요소

1. 여러 화면을 나란히 놓던 비교 레이아웃을 제거하고 `한 슬라이드 = 한 과정`으로 바꿨다.
2. 제품 맥락이 필요한 장면은 전체 화면을 기본으로 두고, 입력란·결과 본문만 1.3–1.5배로 완만하게 확대했다.
3. 확대 화면에 붙였던 오른쪽 아래 설명 라벨은 전부 제거했다.
4. 화면 왼쪽 설명을 `실행 / 확인 / 결과` 세 항목으로 단순화하고, 실제 입력 프롬프트가 필요한 슬라이드에는 별도의 읽기 쉬운 입력 상자를 추가했다.
5. Classic Gems 미리보기와 New Gems 실행은 입력과 결과를 연속 슬라이드로 분리했다.
6. 개인 계정의 반복 응답 선호는 `Gemini 요청사항`, 특정 반복 업무는 Gem, 절차형 작업은 Skill로 구분했다.
7. NotebookLM 마인드맵은 실제 맞춤 설정 입력 화면과 맞춤 결과를 연속 단계로 반영했다.

## 의도적인 차이

- 초기 콘셉트의 콜아웃 선과 다중 번호는 실제 UI 글자를 가릴 수 있어 최종 구현에서 제외했다.
- 강의실 가독성을 위해 장수는 38장 초안에서 57장으로 늘리고 장당 설명 범위를 줄였다.
